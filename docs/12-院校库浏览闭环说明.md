# 院校库浏览闭环说明（2026-09-17）

> 范围：本次只做「院校库浏览闭环」——让已入库的 885 所招生单位在小程序里可检索、可筛选、可浏览，并打通「院校列表 → 院校详情 → 该校专业组合 → 组合详情/对比」。
> 明确不做：微信登录与订阅消息、后台鉴权、Alembic 迁移等（保留待办）。

## 1. 背景与缺口

- 数据规模：院校 885 所（985 39 / 211 76 / 双一流 33 / 普通 737，自划线 34 所）；院校-专业组合 132 个；招录记录 372 条（official 348 / mock 24）；有官方数据的院校 18 所、官方组合 125 个。
- 改造前：小程序 tabBar「院校库」指向 `pages/list/list`（院校专业组合列表），只能看到有组合的约 20 所院校，其余 865 所无处可看；省份/层次 picker 为硬编码，城市与院校类型字段为「暂无」不可用作筛选。

## 2. 后端接口变更（向后兼容）

所有原有字段与参数保持不变，仅新增参数与字段。

### 2.1 `GET /api/v1/institutions`（列表增强）

新增查询参数：

| 参数 | 说明 |
| --- | --- |
| `has_data` | `true` 只返回有官方已审核数据的院校；`false` 只返回无官方数据的院校；不传为全部 |
| `sort` | `default`（985→211→双一流→普通，再按名称）/ `has_data`（有数据院校优先，再按层次、名称）/ `name`（按名称） |

返回项在原有 `InstitutionOut` 字段基础上新增（`InstitutionListItemOut` 继承实现）：

```json
{
  "id": "inst-015",
  "code": "10276",
  "name": "华东政法大学",
  "province": "上海",
  "level": "普通",
  "category": "政法",
  "is_self_draw": false,
  "official_url": "https://yz.chsi.com.cn/sch/schoolInfo--schId-368150.dhtml",
  "combo_count": 2,
  "official_combo_count": 2,
  "official_years": [2026, 2025, 2024],
  "has_official_data": true,
  "latest_data_year": 2026
}
```

### 2.2 `GET /api/v1/institutions/facets`（新增）

供前端动态生成筛选项，避免硬编码省份/层次：

```json
{
  "provinces": [{"value": "北京", "count": 146}, {"value": "江苏", "count": 53}],
  "levels": [{"value": "985", "count": 39}, {"value": "211", "count": 76},
             {"value": "双一流", "count": 33}, {"value": "普通", "count": 737}],
  "categories": [{"value": "理工", "count": 8}, {"value": "综合", "count": 8}],
  "self_draw_count": 34,
  "has_data_count": 18,
  "total": 885
}
```

口径：`provinces` 按数量降序；`levels` 固定顺序且只返回存在的层次；`categories` 只返回有值的院校类型（「暂无」不返回）；`has_data_count` 为有官方已审核数据的院校数。

### 2.3 `GET /api/v1/institutions/{id}/overview`（新增）

院校详情页概览，包含基础信息 + `combo_count` / `official_combo_count` / `official_years` / `latest_data_year` / `latest_updated_at`（最近一次已审核数据更新时间）；院校不存在或未发布返回 404。

### 2.4 复用而非重写

院校详情页的「该校专业组合」直接调用既有 `GET /api/v1/institution-majors?institution_id=...&year=...`，未新增重复接口；对比仍走 `GET /api/v1/institution-majors/compare`。

## 3. 小程序页面结构

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 院校列表（tabBar「院校库」） | `pages/institution/institution` | 搜索（校名/简称/院校代码）、地区 picker（来自 facets）、层次 picker、只看有数据开关、仅自划线开关、排序切换；上拉加载更多（page_size=20）、下拉刷新、总数显示、加载中/空结果/失败三态 |
| 院校详情 | `pages/institution-detail/institution-detail` | 信息卡（名称/代码/地区/自划线/官方链接可复制）、数据概览（组合数、官方数据专业数、覆盖年份、最近更新时间）、该校专业组合列表（复用组合卡片样式与数据质量徽标，可加入对比/跳组合详情/去对比） |
| 分数线查询与对比（保留） | `pages/list/list` | 原院校专业组合列表，保留全部能力，作为普通页面由首页与院校列表页进入 |

tabBar 仍为两项：`首页` / `院校库`（后者改指新院校列表页）。首页「进入院校库」改为 `switchTab` 到新院校库，并新增「分数线查询 / 择校对比」入口（`navigateTo` 到原组合列表页）。

数据标识：有官方数据 → `官方数据 N 个专业`（badge-ok）；仅 mock 组合 → `示例数据（待补充）`（badge-warn）；无组合 → `数据待补充`（badge-gray）。Mock 标识规则未改动。
