# 里程碑 5 交付说明（全流程时间线与节点提醒）

> 状态：后端时间线/节点/订阅/提醒接口与小程序时间线页已完成，本地验证通过。
> 日期：2026-09-04

## 本里程碑做了什么

1. 新增 `process_nodes`、`node_subscriptions` 数据模型。
2. 新增时间线服务 `backend/app/services/timeline.py`：
   - 按月份判断当前阶段。
   - 计算下一节点、近期节点和初试倒计时。
   - 根据订阅的提前天数计算应提醒日期。
3. 新增接口：
   - `GET /api/v1/timeline/current`
   - `GET /api/v1/process-nodes`
   - `POST /api/v1/subscriptions`
   - `GET /api/v1/subscriptions`
   - `DELETE /api/v1/subscriptions/{id}`
   - `GET /api/v1/reminders/upcoming`
4. 内置 13 个关键节点，覆盖大纲、预报名、正式报名、确认、准考证、初试、成绩、自划线、国家线、复试、调剂、录取调档。
5. 小程序新增「考研时间线」页面，展示当前阶段、倒计时、默认任务和近期节点订阅入口。

## 已验证结果

- 以 `today=2026-09-04` 查询，当前阶段为「强化期」，下一节点为「考试大纲发布」，距初试 113 天。
- 订阅「全国硕士研究生初试」成功。
- `reminders/upcoming` 正确返回提前 14 天的提醒日期。

## 首版边界与假设

- 节点日期按 2026/2027 考季的典型日期 Mock，官方发布后可回填 `actual_date`。
- 提醒目前只计算应提醒时间，真实微信订阅消息/推送在后续接入小程序订阅消息时完成。
- 用户身份暂用 `user_id` 占位。
