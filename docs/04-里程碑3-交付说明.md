# 里程碑 3 交付说明（择校测评与梯度推荐）

> 状态：后端测评/推荐引擎与小程序测评页已完成，本地验证通过。
> 日期：2026-09-04

## 本里程碑做了什么

1. 新增 `assessments`、`recommendations` 数据模型。
2. 新增规则推荐引擎 `backend/app/services/recommender.py`：基于「估分 - 近 3 年平均分」和报录比竞争修正，输出冲刺 / 稳妥 / 保底三梯度。
3. 新增测评 API：
   - `POST /api/v1/assessments`
   - `GET /api/v1/assessments/{id}`
   - `GET /api/v1/assessments/{id}/recommendations`
4. 补充 Mock 数据：新增上海大学、苏州大学、南京理工大学、浙江理工大学及 4 个院校专业组合，确保估分 350 的典型用户能获得完整三梯度结果。
5. 小程序新增「智能择校测评」页面，可填写画像并展示推荐结果。

## 已验证结果

以「软件工程、浙江/江苏/上海、估分 350、专硕、不跨考」为例：

- 返回 9 条推荐，覆盖冲刺 / 稳妥 / 保底三个梯度。
- 每条推荐包含概率、平均分差距、报录比、复录比、趋势、数据来源。

## 关键接口示例

```powershell
$body = @{
  undergrad_major = "软件工程"
  target_provinces = @("浙江", "江苏", "上海")
  estimated_total_score = 350
  is_cross_major = $false
  degree_type = "专硕"
} | ConvertTo-Json

Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:8000/api/v1/assessments" `
  -ContentType "application/json" `
  -Body $body
```
