# 研多多全流程人工验收清单

> 用途：验收「一个没有任何考研常识的学生，能否仅靠本产品完成择校、制定计划、按时完成关键节点」。
> 前置：后端已启动，小程序已导入微信开发者工具。

## 一、准备

1. 启动后端。

```powershell
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

2. 用微信开发者工具打开 `frontend/`。
3. 勾选「不校验合法域名、web-view、TLS、HTTPS」。

## 二、学生端主流程

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 首页查看招生单位、专业、组合数量 | 能看到 20、10、24 等 Mock 数量 |
| 2 | 进入院校库，搜索“计算机”，筛选上海、工学、最低平均分 340 | 返回结果均为上海工学且平均分 ≥340 |
| 3 | 打开任一院校专业详情 | 展示历年招录数据、初试/复试信息和来源 |
| 4 | 勾选 3 个院校专业并对比 | 并列展示平均分、报录比、复录比、院线等 |
| 5 | 首页进入智能择校测评，填写软件工程、江浙沪、估分 350、专硕 | 返回冲刺/稳妥/保底三梯度及理由 |
| 6 | 首页进入生成学习计划，填写四科目标分和当前分 | 生成每日任务，四科按短板分配时长 |
| 7 | 首页进入今日打卡，提交学习时长 | 打卡成功，近 7 天概览更新 |
| 8 | 首页进入考研时间线 | 显示当前阶段、距初试倒计时、下一节点和默认任务 |
| 9 | 时间线中订阅“全国硕士研究生初试” | 提示订阅成功，可在接口查看提前提醒日期 |

## 三、后台主流程

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 打开 `http://127.0.0.1:8000/admin.html` | 管理后台可正常打开 |
| 2 | 批量导入一份 CSV/Excel | 返回新增/更新数量 |
| 3 | 在纠错审核页审核一条待处理纠错 | 状态变为已审核 |
| 4 | 发布一篇政策/资讯文章 | 文章在公开接口可查询 |

## 四、验收结论

- [ ] 学生无需外部搜索即可完成择校。
- [ ] 学生能生成并执行每日计划。
- [ ] 关键节点和时间线清晰可见。
- [ ] 后台能维护数据、审核纠错、发布资讯。
- [ ] 所有 Mock 数据均有“示例数据”标识或来源字段。
