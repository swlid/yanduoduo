# 里程碑 4 交付说明（学习规划与打卡）

> 状态：后端计划生成/打卡/进度/报告与小程序的计划、打卡页面已完成，本地验证通过。
> 日期：2026-09-04

## 本里程碑做了什么

1. 新增 `task_templates`、`study_plans`、`plan_tasks`、`check_ins`、`study_reports` 数据模型。
2. 新增计划生成引擎 `backend/app/services/planner.py`：
   - 按「目标分 - 当前分」的短板权重自动分配每日科目时长。
   - 按计划进度自动划分基础期 / 强化期 / 冲刺期。
   - 支持过期未完成任务顺延。
3. 新增接口：
   - `POST /api/v1/plans/generate`
   - `GET /api/v1/plans`
   - `GET /api/v1/plans/{id}`
   - `GET /api/v1/plans/{id}/calendar`
   - `POST /api/v1/plans/{id}/rollover`
   - `POST /api/v1/plans/{id}/tasks/{task_id}/complete`
   - `POST /api/v1/check-ins`
   - `GET /api/v1/check-ins`
   - `GET /api/v1/progress`
   - `GET /api/v1/reports/{period}`
4. 小程序新增「生成学习计划」和「今日打卡」页面，并接入首页入口。

## 已验证结果

- 7 天计划生成 28 条每日任务，按科目短板分配分钟数。
- 打卡、补卡、进度统计、周报告均正常。
- 顺延接口把 3 天未完成任务顺延到目标日，且 `rollover_count` 正确返回。

## 首版边界与假设

- 用户身份暂用 `user_id` 字符串占位，登录体系后续接入。
- 提醒时间只保存在计划字段中，真实推送/延迟队列在里程碑 5 的节点提醒中统一实现。
- 打卡与计划任务暂未强制一对一绑定，进度以打卡记录为准。
- 周/月报告为即时生成并落库快照，不包含 AI 总结。
