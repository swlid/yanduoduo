# 里程碑 2 交付说明（后端 MVP）

> 状态：后端查询/筛选/详情/对比 MVP 已完成并本地验证通过。
> 日期：2026-08-31

## 本里程碑做了什么

1. 建立 `backend/` 仓库骨架：FastAPI 应用、SQLAlchemy 模型、Pydantic Schema、API 路由、Mock 种子数据、Docker Compose 与 `.env.example`。
2. 落地核心数据模型：`institutions`、`majors`、`institution_majors`、`admission_stats`，遵循「院校—专业—年度—指标」结构。
3. 实现院校/专业查询、组合筛选、院校专业详情、横向对比接口。
4. 内置 16 所院校、10 个专业、20 个院校专业组合、每年 3 年招录数据，共 60 条 Mock 招录记录。
5. 提供 SQLite 本地运行方案和 PostgreSQL/Redis Docker Compose 联调方案。

## 已验证结果

- `GET /health` 返回 `{"status":"ok"}`。
- 院校列表：`total=16`，分页正常。
- 组合筛选「上海 + 工学 + 平均分 ≥340」返回 3 条，字段与筛选逻辑符合预期。
- 对比接口支持 4 个 ID、正确返回 `missing_ids`。
- 详情接口返回 3 个年份的招录数据。

## 运行方式

```powershell
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Swagger：<http://127.0.0.1:8000/docs>
